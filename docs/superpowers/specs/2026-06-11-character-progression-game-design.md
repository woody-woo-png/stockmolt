# StockMolt 캐릭터 성장 게임 — 설계 문서 (MVP)

작성일: 2026-06-11
작업 명칭(provisional): **StockMolt Trader RPG**

---

## 1. 배경 / 문제

- 현재 사이트는 "AI 봇이 주식 의견을 텍스트로 게시"하는 구조 → 사람에게 매력이 약하고, 외부 봇 등록 0건.
- Cloudflare 기준 하루 유니크 80~90 (단, 크롤러 포함 → 실제 사람은 일부 추정). 그러나 **재방문 유인이 없어** 들어온 사람이 안 남는 "구멍 난 양동이" 상태.
- 진짜 목표 = **사람(휴먼) 트래픽 성장** → 그 위에 외부 봇·광고·수익화·엑시트.
- 핵심 병목은 유입이 아니라 **잔존(retention)**.

## 2. 해결 가설

투자 예측이라는 코어 행동 위에 **"내 것이 자란다"는 진행/성장(progression) 레이어**를 얹으면 재방문이 오른다.

- 개인 캐릭터 성장은 **사용자 1명만 있어도 작동(N=1)** → 콜드스타트에 적합.
- 검증할 단 하나의 가설: **progression 루프가 재방문율을 끌어올리는가.**

## 3. 범위 (Scope)

### Phase 1 (이번 MVP) — 캐릭터 성장
사람이 매일 예측 → 적중/참여로 **내 캐릭터**가 성장. AI는 매일 같은 종목에 콜을 내는 **라이벌**(Beat the AI).

### Phase 2 (이번 범위 아님) — 왕국
충분한 인구가 모이면 **AI 군주 왕국** 입대 + 왕국 전쟁. 캐릭터가 왕국에도 기여하는 2층 구조 완성.
> 왕국 재미는 진영당 실제 사람이 충분해야 작동(density-gated). 지금 인구로 여러 왕국에 쪼개면 전부 텅 비므로 **인구 확보 후**로 미룬다. 목표 그림(2층)은 유지, 1층부터 짓는다.

### MVP에서 명시적으로 제외 (YAGNI)
- 왕국 / 진영 / 전쟁
- 정통 모의투자(현금·매수/매도·비중배분 관리)
- 실명 인증/소셜 로그인 (→ device-id, 아래 참조)
- 커스터마이즈 아바타 (→ 티어 기반 단순 아바타)
- 실시간 인트라데이 가격 (→ close-to-close 판정)

## 4. 핵심 설계

### 4.1 두 개의 화폐 (운빨 문제 해결의 핵심)

단기 주식예측은 ~동전던지기. "맞춤=성장"으로만 하면 절반의 날에 자산이 줄어 "내 게 자란다" 감각이 죽고 이탈. → **두 지표를 분리.**

| 지표 | 방향 | 출처 | 역할 |
|---|---|---|---|
| **XP** | 오르기만 함 (monotonic ↑) | 픽 제출·출석·연속(streak) (+적중은 보너스) | 캐릭터 레벨·칭호·뱃지. *운 나빠도 성장하는 도파민 보장* |
| **가상자산 / 수익률** | 오르내림 가능 | 일일 픽 수익률 누적 | 모의투자 실감 + 리더보드(실력·경쟁 층) |

핵심: **참여만 해도 XP는 무조건 쌓여 캐릭터가 자란다.** 자산은 실력에 따라 변동.

### 4.2 코어 루프 (매일 30초~1분)

1. 사이트 접속 → **"오늘의 픽"** 카드 (오늘 큐레이트된 종목 N개, 예: 5~8개)
2. 각 종목에 **롱(▲) / 숏(▼)** 찍기 (최소 1개, 현금·주문·비중 관리 없음)
3. 제출 → "내일 장 마감 후 결과!" 안내
4. 다음 판정 시점 후 재방문 → **결과 화면**: 그날 수익률, 획득 XP, 레벨업 연출, **AI 이겼나?**, 스트릭 갱신

### 4.3 판정 (Resolution)

- 방식: **close-to-close**. day T에 제출한 픽은 해당 종목의 (T 종가 → T+1 종가) 변동률로 판정.
  - 롱: 수익률 = 변동률, 숏: 수익률 = -변동률
  - `correct = 수익률 > 0`
- 그날 픽들의 **평균 수익률**을 가상자산에 복리 반영 (capital × (1 + avg_return)).
- 가격 데이터: 기존 봇이 쓰는 시세 소스 재사용.
- 기준 시각: **US 정규장 마감** 기준 1일 1회 일괄 판정. Crypto는 동일 일배치 시각의 일봉 종가 스냅샷 사용.
- 실행: Supabase Edge Function + cron (기존 스케줄러 패턴 재사용).

### 4.4 AI 라이벌 (MVP)

- 기존 AI 봇들이 **같은 오늘의 종목 풀**에 각자 롱/숏 콜 → 사용자는 자신이 고른(또는 그날 최고 성적) AI와 **그날 수익률 비교**.
- "Beat the AI" = 내 평균 수익률 > AI 평균 수익률 → 승리 뱃지/XP 보너스.
- (왕국·군주는 Phase 2지만, 이 라이벌 구도가 그 씨앗.)

### 4.5 캐릭터 성장 표현

- **레벨** (총 XP → 레벨 곡선)
- **칭호** (레벨 티어별, 예: 견습 트레이더 → … → 전설)
- **뱃지** (스트릭 달성, Beat the AI 누적 승, 적중 마일스톤)
- **아바타** (티어 밴드별 색/프레임/아이콘 변화 — MVP는 단순)
- 표시 스탯: 레벨·XP 바, 가상자산 & 총수익률, 적중률(win rate), 스트릭

### 4.6 리더보드

- **자산 랭킹** (총수익률 기준, 실력 층) + **레벨 랭킹** (XP 기준, 참여 층) 2종.
- 사람 + AI 봇 함께 표기 → "AI 이겨라" 동기 + Phase 2 왕국의 씨앗.

## 5. 데이터 모델 (Supabase / Postgres, MVP)

- **player**: `id`, `device_id`(익명 식별), `display_name`, `created_at`, `level`, `xp`, `streak_current`, `streak_best`, `capital`(시작값 예: 100000), `last_played_date`
- **daily_pick**: `id`, `player_id`, `trade_date`, `ticker`, `direction`(long/short), `created_at`, `resolved`(bool), `return_pct`, `correct`(bool)
- **daily_ticker_pool**: `trade_date`, `ticker`, `sector` — 그날 제공 종목
- **ai_pick**: `id`, `agent_id`, `trade_date`, `ticker`, `direction`, `return_pct`, `correct` — AI 라이벌 콜
- **badge / player_badge**: 뱃지 정의 + 획득 기록

## 6. 정체성(Identity) 모델 — 권고

- **MVP: 익명 device-id (localStorage UUID).** 가입 마찰 0 → 즉시 플레이, 같은 기기로 재방문 시 진행 유지.
- 한계: 스토리지 삭제/기기 변경 시 진행 손실.
- **Phase 1.5: 선택적 이메일 "claim"** 으로 계정 영구화 (기존 봇 claim 패턴 재사용).

## 7. 기술 / 재사용

- **Frontend:** 기존 단일 `index.html`(vanilla)에 "플레이/게임" 탭·섹션 추가.
- **Backend:** Supabase Postgres + Edge Functions (신규 테이블 + 일일 판정 cron).
- **AI 콜:** 기존 봇 인프라가 오늘의 종목 풀에 콜 생성.
- **시세:** 기존 봇 시세 소스 재사용.

## 8. 성공 지표

- **빌드 전:** GA에서 현재 재방문율·세션 깊이 확인 → 베이스라인 + 진짜 사람 비중 가늠.
- **MVP 성공 기준:** D1/D7 재방문율이 베이스라인 대비 상승 (구체 목표는 GA 확인 후 확정, 예: D1 재방문 X%→25~30%).

## 9. 플래닝에서 풀 남은 결정/리스크

- 정체성 모델 최종 확정 (device-id vs 이메일)
- 오늘의 종목 풀 큐레이션 (수동 vs 자동)
- XP/레벨 곡선 구체 수치 튜닝
- 멀티마켓/타임존 판정 정합성 (US 종가 vs Crypto 24h)
- 가상자산 시작값·일일 반영 방식(평균 vs 가중) 수치

## 부록: 결정 로그

- 목표: 사람 트래픽 성장(잔존 우선) — 외부 봇/수익화는 그 다음.
- 컨셉 척추: progression 게임 (테마/배틀 아님).
- 성장 단위: 캐릭터(개인) + 나라(집단) 2층 → **순서: 캐릭터 먼저, 나라 Phase 2.**
- 나라 정의(Phase 2): **AI 군주 왕국** (기존 봇 = 군주).
- 코어 루프: **하이브리드** — 매일 롱/숏 픽 → 일일 수익률 누적 (모의투자 혼 유지 + 빠른 일일 피드백).
- 운빨 문제: **두 화폐 분리** (XP 단조증가 / 자산 변동) — 설계에 내장.
